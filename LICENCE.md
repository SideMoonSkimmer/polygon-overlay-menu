## 🧩 About

**Polygon Companion** is a curated list of Polygon open-source tools:

- **Overlays** — on-screen helpers, layout notes, HUD panels, session timer
- **Quality-of-Life Helpers** — config presets, keybind notes, overlay visibility controls
- **Research Notes** — input layout studies and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Session Timer — track play time per round
- HUD Panel — on-screen stats layout notes
- Keybind Overview — review current bindings in an overlay
- Sensitivity Notes — adjust mouse feel for study (0.1x to 5x)

### Wallhack
- Overlay Themes — browse color presets and layouts
- Crosshair Notes — organize reticle styles
- Frame Counter — improved visibility of performance stats

### Aimbot
- Warmup Notes — segment study on any map
- Movement Drill Notes — chain practice maneuvers
- Config Snapshot — save and reload overlay settings
